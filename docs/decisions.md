- 2026-11-11（PR #22）：**サイトマップを型ごとの6ファイルに分ける。** 理由：Search Console で、どの型が登録されていないかを見るため。

- 2026-11-11：**外からの入口は、費用のかからないものから進める。** X の投稿 → note・Zenn の記事 → プロフィールからのリンクの順。相互リンクの依頼や、リンク集への大量登録はしない。

## 広告・AdSense の審査
- 2026-11-28（運営者の依頼・チャット）：**AdSense の審査は「有用性の低いコンテンツ」で不承認（ads.txt は承認済み）。評価軸を「ページ数・件数」から「インデックスされたページ1枚あたりの価値」に変える。** データの収集は今までどおり増やすが、集めた1件ごとに index のページを作ることはやめる。理由：直近90日の火事のページの多くが「〇〇で火事が報道されました」の1文と報道へのリンク1本で、Google のスパムポリシーの「寄せ集め（scraped）」「大量生成（scaled content abuse）」に当たると見たため。AdSense はサイト全体で判定する。やることと再申請の条件は `docs/adsense-remediation.md`（自動改善は作業前にこれも読む）
- 2026-11-28（運営者の依頼・チャット）：**AdSense の再申請までのつなぎに、審査のない忍者AdMax を出す。** AdSense の `slot` が空のあいだだけ、同じ位置（区切りの間・1ページ2つまで）に出し、`slot` が入れば自動で AdSense に戻る。オーバーレイ・画面下固定・ポップアップの枠は使わない（広告の形式の決まりは変えない）。タグは `site/ads.json` の `admax.tag` に管理画面のものを貼り、`*.shinobi.jp` 以外の script・iframe・イベント属性が混じると生成を止める。理由：AdSense の再申請まで早くても1か月ほどかかり、その間に広告の枠でどれくらい収益が出るかを知るため

# 改善の候補（backlog）

自動改善が毎日ここから1つ選ぶ。毎週の「外を見る」で5つ以上足す。
**点数 ＝ 効果（1〜5）× 確度（1〜5）÷ 手間（1〜5）**。区分は「自動」か「承認」（`docs/autopilot.md` の表）。
状態は「候補」「実施中」「済」「見送り」。見送りには理由を書く。
